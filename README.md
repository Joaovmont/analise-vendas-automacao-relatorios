Análise de Dados de Vendas com Automação de Relatórios

Objetivo: Este projeto tem como objetivo analisar uma base de dados de vendas, identificar padrões e gerar insights relevantes, além de automatizar o envio de relatórios por e-mail.


Ferramentas utilizadas:

Python, Pandas, SMTP, VSCode


Etapas do projeto:

Coleta e carregamento dos dados
Limpeza e tratamento dos dados
Análise exploratória (EDA)
Geração de insights
Automação do envio de relatórios


Principais resultados:
Identificação de padrões de vendas
Geração de insights para tomada de decisão
Redução do tempo de análise com automação
